# 🗂️ Task Management API

> A production-ready RESTful backend API built with **FastAPI**, featuring secure authentication, role-based access control, and a full-featured task management system.

---

## 📌 Overview

This project is a production-style backend API designed for scalability, security, and clean architecture. It supports user authentication via JWT tokens, role-based access control (RBAC) for permission management, and a complete task management system with full CRUD operations.

Built with modern Python best practices, the API is auto-documented via Swagger UI and ReDoc, making it easy for developers to explore and integrate.

---

## ✨ Features

- 🔐 **JWT Authentication** — Secure user registration, login, and token-based session handling
- 👥 **Role-Based Access Control** — Fine-grained permissions for Admin, Manager, and User roles
- ✅ **Task Management** — Create, assign, update, and track tasks with status management
- 🛡️ **Input Validation** — Request validation and structured error responses via Pydantic
- 📄 **Auto-Generated Docs** — Interactive API docs available via Swagger UI and ReDoc
- 🧱 **Modular Architecture** — Clean, scalable project structure ready for production deployment

---

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Framework | FastAPI |
| Language | Python 3.11+ |
| Authentication | JWT (JSON Web Tokens) |
| Validation | Pydantic v2 |
| Database ORM | SQLAlchemy |
| Database | PostgreSQL |
| Migrations | Alembic |
| Server | Uvicorn |
